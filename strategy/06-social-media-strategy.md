# 6. Social Media Strategy

Each platform has a different job. Content is planned separately for Instagram, LinkedIn and the website.

## Instagram

|  |  |
|---|---|
| Role | Primary awareness and community channel for students (18–24) |
| Audience | Ravi (students), some Sneha |
| Frequency | 5–6 feed posts/week + daily Stories |
| Formats | Reels (9:16), carousels (4:5), Stories with polls/quizzes/countdowns, Lives |
| Best times (IST) | Weekdays 7–10 PM, weekends 11 AM–1 PM (starting hypothesis — confirm with Insights after week 2) |
| Tone | Friendly, energetic, relatable; Telugu-English mix in Reels |
| CTA | Follow, save, 'link in bio' to register, DM keywords (e.g. DM 'AI' for the workshop link) |
| KPIs | Reach, follower growth, saves, shares, profile link clicks |

## LinkedIn

|  |  |
|---|---|
| Role | Credibility, career-switcher acquisition and employer/college relationships |
| Audience | Sneha (switchers), final-year students, TPOs, hiring partners |
| Frequency | 3–4 posts/week (company page) + founder/mentor reposts |
| Formats | Text posts with a strong first line, document carousels (PDF), polls, event pages, alumni stories |
| Best times (IST) | Tue–Thu, 8–10 AM and 12–2 PM (starting hypothesis) |
| Tone | Professional, helpful, insight-led; no hard selling |
| CTA | Comment, follow the page, register for the event, book a counselling call |
| KPIs | Impressions, engagement rate, follower growth, event registrations |

## Website / Blog

|  |  |
|---|---|
| Role | Conversion hub and SEO engine — every campaign lands here |
| Audience | All personas, especially high-intent searchers and parents |
| Frequency | 1 SEO blog/week + 2 landing pages (workshop, challenge) |
| Formats | Long-form blog posts (1,200–1,800 words), landing pages, FAQ, alumni stories page |
| Best times (IST) | Publish Tuesday morning; share on socials the same day |
| Tone | Clear, trustworthy, detailed |
| CTA | Register for workshop, book counselling call, download syllabus |
| KPIs | Sessions, organic traffic, landing-page conversion rate, form fills |

## YouTube Shorts (supporting)

|  |  |
|---|---|
| Role | Repurpose Instagram Reels for extra reach at zero extra production cost |
| Audience | Students who search tutorials |
| Frequency | 3 Shorts/week (repurposed Reels) |
| Formats | Shorts (9:16, under 60 s) |
| Best times (IST) | Evenings |
| Tone | Same as Instagram |
| CTA | Subscribe, link to workshop |
| KPIs | Views, subscribers |

## WhatsApp community (supporting)

|  |  |
|---|---|
| Role | Nurture leads and reach parents directly |
| Audience | Workshop registrants, parents |
| Frequency | 2–3 broadcasts/week |
| Formats | Reminders, short videos, polls, PDF guides |
| Best times (IST) | 7–9 PM |
| Tone | Personal and helpful; Telugu + English |
| CTA | Attend workshop, book call |
| KPIs | Members, attendance rate |
