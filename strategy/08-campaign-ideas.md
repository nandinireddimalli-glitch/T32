# 8. Campaign Ideas

Four campaigns move the audience through the funnel: awareness → leads → engagement → enrolment.

## Projects > Certificates

|  |  |
|---|---|
| When | Week 1 (Day 1–7) |
| Goal | Awareness |
| Big idea | A myth-busting series showing that recruiters look at what you've built, not how many certificates you have. Sets up the brand's core belief. |
| Assets | Opening Reel, LinkedIn document carousel, SEO blog, Story polls |
| Success metric | Reach 60,000 accounts; +500 Instagram followers |

## Build Your First AI App (free workshop)

|  |  |
|---|---|
| When | Week 2 (Day 5–14, workshop on Sat 12 Dec) |
| Goal | Lead generation |
| Big idea | A free 3-hour online + offline workshop where beginners build and deploy a simple AI app. Registration collects leads; attendees get a follow-up counselling call. |
| Assets | Announcement Reel, event page, countdown Stories, WhatsApp reminders, live coverage, recap Reel |
| Success metric | 600 registrations, 50% attendance, 150 counselling calls |

## #ProjectNotPromise Challenge

|  |  |
|---|---|
| When | Week 3 (Day 15–22) |
| Goal | Engagement + UGC |
| Big idea | Build anything in 7 days, post it with #ProjectNotPromise and tag @vidyutlabs. Top 3 win 50% / 25% / 25% scholarships; community votes for a 'People's Choice'. |
| Assets | Launch Reel, rules landing page, idea carousel, UGC reposts, voting Stories, winners Reel |
| Success metric | 150 submissions; 400 hashtag uses; engagement rate ≥6% |

## New Year, New Stack

|  |  |
|---|---|
| When | Week 4 (Day 22–30) |
| Goal | Conversion |
| Big idea | Enrolment push for the January 2027 cohort with an early-bird fee ending 30 Dec. Uses alumni stories, a transparent fee/EMI explainer and a Telugu parent open house to remove objections. |
| Assets | Cohort carousel, syllabus document, parent open house, countdown Stories, retargeting ads |
| Success metric | 40 enrolments; CAC ≤ ₹3,750 |
