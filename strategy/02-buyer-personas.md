# 2. Buyer Personas

Three personas cover the student, the career switcher and the parent who funds the decision.

## Persona 1: Ravi Teja — *The Final-Year Hustler*

> "I've done 12 online certificates but still no interview calls."

|  |  |
|---|---|
| Age | 21 |
| Background | B.Tech CSE, final year, private college near Warangal |
| Goals | Land a product-company job before graduation; Build a GitHub portfolio that stands out; Crack technical interviews |
| Pain points | No real-world projects; Doesn't know which stack to pick; Limited budget |
| Where they spend time | Instagram Reels, YouTube, LinkedIn, College WhatsApp groups |
| Objections | 'I can learn this free on YouTube.' '₹30k is a lot for my family.' |
| Key message | **Ship 4 projects recruiters actually open — with a mentor checking your code.** |
| Content that converts them | Project-idea carousels, Roadmap posts, Free workshop, #ProjectNotPromise challenge |

## Persona 2: Sneha Reddy — *The Career Switcher*

> "I don't want to be stuck in the same role for five more years."

|  |  |
|---|---|
| Age | 26 |
| Background | Manual tester at an IT services firm, Hitech City |
| Goals | Move into a developer or AI role; Get a meaningful salary jump; Learn without quitting her job |
| Pain points | Only evenings and weekends free; Worried it's 'too late' to switch; Past courses felt like lectures, not building |
| Where they spend time | LinkedIn, YouTube, Instagram (evenings), Google search |
| Objections | 'Will I manage this with a full-time job?' 'Will companies hire a switcher?' |
| Key message | **Weekend cohort, EMI options and alumni who switched careers just like you.** |
| Content that converts them | Alumni switch stories, LinkedIn document carousels, Fee/EMI explainer, Day-in-the-life Reels |

## Persona 3: Srinivas Rao — *The Parent-Investor*

> "There are so many institutes. How do I know this one is genuine?"

|  |  |
|---|---|
| Age | 49 |
| Background | Government employee in Guntur, father of a 3rd-year B.Tech student |
| Goals | See his child get a stable, well-paid job; Spend money on something that clearly works |
| Pain points | Bad past experience with a coaching centre; Can't judge technical quality himself |
| Where they spend time | WhatsApp, Facebook, YouTube (Telugu), Word of mouth |
| Objections | 'Is there any guarantee?' 'Can I visit and meet the people?' |
| Key message | **Transparent outcomes, real alumni you can call, and an open house in Telugu.** |
| Content that converts them | Parent open house, Telugu alumni video testimonials, 'Honest answers' FAQ posts, WhatsApp broadcast |
